Steps for creating an STable: in the Scope View…
1.Create the STable.
2.Set the STable selector string to the name of the arraylist in the model:
rosterTable.setSelectorString("rosterEntries");
3.Set the column selector strings to show which fields in the ItemModel to display in the STable:
String[] columnSelects = {"name","position","number"};
        rosterTable.setColumnSelectorStrings(columnSelects);
4.  Set the column names:
String[] columnNames = {"Name","Position","Number"};//set the column names/column header values
        rosterTable.setColumnNames(columnNames);
