Steps for creating an SComboBox: in the Scope View…
1.Create the SComboBox.
2.Set the SComboBox selector string to the name of the arraylist in the model:
  teamCombo.setSelectorString("teams");//map the SComboBox to the arraylist returned by getTeams() in the TCDemoModel
3.Set the renderer selector to the field within the ItemModel object that you want to display:
teamCombo.setRendererSelector(Selector.fromString("fullName"));//map the SComboBox to display this field in the objects contained in the TCDemoModel
4.Set the selection selector to the selected ItemModel variable from the Model.
teamCombo.setSelectionSelectorString("selectedTeam");//populate this Team object in the TCDemoModel with the selected item in the SComboBox
