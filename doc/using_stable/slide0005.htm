Steps for creating an SComboBox: in the Scope Model…
1.  Create an ItemModel object for the type of item to be displayed in the SComboBox.
2.Create an instance variable, using as the type the ItemModel object you created in Step 1.  This will represent the selected object in the SComboBox.
3.Create an arraylist to hold the ItemModel objects in the SComboBox.
4.Create a public final static selector constant that maps to the selected ItemModel object from step 2.
public final static Selector SELECTED_TEAM = Selector.fromString("selectedTeam");
private Team selectedTeam;
5.Create getter and setter methods for the arraylist and itemmodel variables.
6.In the setter for the selected ItemModel object, fire a ModelChangeEvent to automatically refresh the view when the model data changes:
this.fireModelChange(ModelChangeEvent.VALUE_CHANGED, SELECTED_TEAM);
