Steps for creating an STable: in the Scope Model…
1.Create an ItemModel object for the type of item to be displayed in the STable.  This object represents a row in the database, but can have additional fields that are not displayed in the table row.
2.Create an ArrayList to hold the ItemModel objects to be displayed in the STable.
3.Populate the ArrayList with ItemModel objects.
4.Create a public final static selector constant that maps to the ArrayList of
ItemModel objects, so when it changes the view can be updated:
public final static Selector ROSTER = Selector.fromString("rosterEntries");
5.Create getter and setter methods for the ArrayList. In the setter method fire a ModelChangeEvent to automatically refresh the view when the model data changes:
this.fireModelChange(ModelChangeEvent.VALUE_CHANGED, this.ROSTER);
