Issuing and Handling Controls
 
       
From a View, a control can be fired via:
•issueControl(new ControlID(“SAVE”));
•Sbutton save = new SButton(SwingFormController.SAVE_FORM);
•STextField name = new STextField();
         name.setControlID("SAVE");
From a Controller or Sub-Controller:
        handleControl(new ControlID(“SAVE”);
