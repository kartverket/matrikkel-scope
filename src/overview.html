Abstract

Scope is a framework built around an extensible implementation of the Hierarchical Model-View-Controller (HMVC) pattern similar to the pattern described in HMVC: The layered pattern for developing strong client tiers . It provides an easy-to-use Java library that can be used as a basis for component-oriented application development following the layered architecture detailed in Sun's J2EE and in Cheesman/Daniels: UML Components .

Applications developed using Scope are "view-agnostic": a Swing application uses the same infrastructure and patterns as a web application that happens to use XML/XSLT to generate HTML. The framework has been used in production systems built using the default Swing and Servlet implementations, as well as proprietary VoiceXML, ColdFusion and custom XML/XSLT implementations.

Scope provides the following major subsystems:

  • An HMVC implementation in which Controllers respond to Control objects issued from Views as a result of user interaction, or from child Controllers in the chain of responsibility. See {@link org.scopemvc.core.Controller Controller} and {@link org.scopemvc.core.Control Control}. This infrastructure acts as a layer of abstraction from low-level user interface handling (eg Swing's various Events, and web-apps' HTTP request/response mechanism).
  • Infrastructure for binding models to views with full two-way synchronisation: change the view and the model is updated, and vice-versa. (Obvious limitations exist with web applications that cannot update HTML when a model on the web server updates.)
  • Wrappers around common Swing components to implement two-way data binding with validation. See {@link org.scopemvc.view.swing}.
  • A servlet implementation using XSLT to transform model XML into HTML. The servlet implementation supports persistent per-user application state if required, and automatic repopulation of model objects from form parameters in an HTTP request. See {@link org.scopemvc.view.servlet.xml} and {@link org.scopemvc.controller.servlet.ScopeServlet ScopeServlet}.
  • Infrastructure that allows Scope to act on arbitrary JavaBean model objects. This infrastructure is designed to be decoupled in such a way that an alternative can be plugged in, for example to act on JMX MBeans. Refer to base classes: {@link org.scopemvc.core.ModelManager ModelManager}, {@link org.scopemvc.core.PropertyManager PropertyManager}, {@link org.scopemvc.core.ActionManager ActionManager}, {@link org.scopemvc.core.EditorManager EditorManager}. And then see the JavaBeans implementation: {@link org.scopemvc.model.beans.BeansPropertyManager BeansPropertyManager}, {@link org.scopemvc.model.beans.BeansActionManager BeansActionManager}, {@link org.scopemvc.model.beans.BeansEditorManager BeansEditorManager}. See examples for use of JavaBean model objects, for example samples.helloworld.HelloModel.
  • An implementation of "active" model objects that broadcast changes in their state to allow views to update automatically. See {@link org.scopemvc.model.basic.BasicModel BasicModel}. A set of "active" collection models are also provided. See {@link org.scopemvc.model.collection}. Use of these base classes is optional but convenient in complex applications that use a rich GUI, eg Swing, in which fully automated synchronisation between model and view is desirable. However, even where this is not feasible, Scope's Swing implementation without "active" models greatly simplifies the developer's job -- see the samples.
  • Support for localisation of user messages. See {@link org.scopemvc.util.UIStrings UIStrings} and {@link org.scopemvc.util.LocalizedException LocalizedException} and {@link org.scopemvc.controller.basic.BasicController#handleControlException BasicController.handleControlException} for the default exception handling behaviour.
  • Support for conversion of arbitrary datatypes to and from their String representation. See {@link org.scopemvc.util.convertor.StringConvertor StringConvertor}.
  • A comprehensive jUnit unit test suite to ensure a known quality level. The test suite is: test.SuiteScope.
