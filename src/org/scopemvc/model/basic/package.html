This package provides {@link org.scopemvc.model.basic.BasicModel BasicModel}, a simple implementation of the {@link org.scopemvc.core.ModelChangeEventSource ModelChangeEventSource} interface, with a ModelChangeEvent infrastructure based around synchronous event despatch similar to the JavaBeans PropertyChangeSupport strategy. EVent despatch is handled by the {@link org.scopemvc.model.basic.ModelChangeEventSupport ModelChangeEventSupport} delegate.
