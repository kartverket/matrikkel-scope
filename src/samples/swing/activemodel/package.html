A trivial example of an active model that implements ModelChangeEventSource by subclassing BasicModel. This is the same application as "helloworld2". The changes are to the model and to the Controller which no longer needs to manually force its view to refresh whenever the model changes state (since it fires a ModelChangeEvent that the view reacts to).

The ActivemodelModel

This is exactly the same as the Hello2Model except that the setName method includes a line to fire a ModelChangeEvent: 

    public void setName(String inName) {
        name = inName;
        fireModelChange(VALUE_CHANGED, Selector.fromString("name"));
    }

The ActivemodelController

This is the same as the Hello2Controller except that it no longer includes code to refresh its view after changes to the model's state have occured. The refresh is now taken care of with the ModelChangeEvent firing.

The Views

The Views are exactly the same as in "helloworld2".
