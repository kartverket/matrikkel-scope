Simple application based on the HelloWorld example, except that the Controller manages two views on the same Model.

The default implementation of BasicController assumes that only one View per Controller is active at any time. To have two active views needs a little extra work to establish the binding between model and view (usually done behind the scenes in BasicController when setModel and setView are used).

The extra steps can be seen in the source below:

  • a View has a parent Controller set using View.setController()
  • a View is bound to its model using View.setBoundModel()
  • Views are shown with showView(View) and hidden with hideView(View)
public class MultiviewController extends BasicController {
	
	private MultiviewView2 view2;

    public MultiviewController() {
        setModel(new MultiviewModel());
        setView(new MultiviewView1());
        
        view2 = new MultiviewView2();
        view2.setController(this);
        view2.setBoundModel(getModel());
    }

    public void startup() {
        showView();
        showView(view2);
    }
    
    public void shutdown() {
    	super.shutdown();
    	hideView(view2);
    }
}
