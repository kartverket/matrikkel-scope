A simple example to demonstrate the use of a bound SList widget with synchronized update of a view on the current list selection.

The Application

The application presents a view with a list of customers on the list and a panel with details of the selected customer on the right. As the user changes the selected item in the list, the details panel on the right updates automatically to view the details of the selection.

The ListController

We respond to a Control issued by the SList when the user changes the current selection to cause the customer details view to refresh. This refresh could be automatically done by the framework if the model fired events when its state changes -- see ***** example.

The "EXIT_CONTROL_ID" is handled in a reasonable way by the BasicController superclass so we don't even need to handle this Control. BasicController also provides a reasonable startup() method (called by the Launcher) that we use. 

public class ListController extends BasicController {

    public static final String SELECTED = "Selected";

    public ListController() {
        setModel(new ListViewModel());
        setView(new ListView());
    }

    protected void doHandleControl(Control inControl) throws ControlException {
        if (inControl.matchesID(SELECTED)) {
            doSelected();
        }
    }

    protected void doSelected() {
        ((ListView)getView()).refreshCustomerView();
    }
}

The ListCustomerModel

This is the model that the list contains. A familiar-looking model with three properties: a String name, String address and int age. 

public class ListCustomerModel {

    private String name;
    private String address;
    private int age;

    public ListCustomerModel() {
    }

    public ListCustomerModel(String inName, 
                             String inAddress, 
                             int inAge) {
        name = inName;
        address = inAddress;
        age = inAge;
    }

    public String getName() {
        return name;
    }

    public void setName(String inName) {
        name = inName;
    }

    public String getAddress() {
        return address;
    }

    public void setAddress(String inAddress) {
        address = inAddress;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int inAge) {
        age = inAge;
    }
}

The ListViewModel

A simple model that includes two properties: a list of customers (of type ListModel) and the currently selected customer (of type ListCustomerModel). 

public class ListViewModel {

    private ArrayList customers = new ArrayList();
    private ListCustomerModel selection;

    public ListViewModel() {
        addCustomer(new ListCustomerModel("Steve", "London", 105));
        addCustomer(new ListCustomerModel("Trevor", "Kendal", 3));
        addCustomer(new ListCustomerModel("Johan", "Kendal", 40));
        addCustomer(new ListCustomerModel("Bert", "Eynsham", 60));
    }

    public ArrayList getCustomers() {
        return customers;
    }

    public void addCustomer(ListCustomerModel inCustomer) {
        customers.add(inCustomer);
    }

    public ListCustomerModel getSelection() {
        return selection;
    }

    public void setSelection(ListCustomerModel inCustomer) {
        selection = inCustomer;
    }
}

The second property is bound to the List widget so that it will change automatically to track the user's current selection. This property is also bound to the "customer details" view.

The ListView

A simple view that contains an SList widget on the left and a SPanel with a number of SLabels viewing details of the selected customer to the right. 

    public ListView() {

        setLayout(new BorderLayout(0, 12));

        SList l = new SList();
        l.setSelector("customers");
        l.setRendererSelector("name");
        l.setSelectionSelector("selection");
        l.setChangeSelectionControlID(ListController.SELECTED);
        JScrollPane left = new JScrollPane(l);

        customerView = new SPanel();
        customerView.setSelector("selection");
        customerView.setLayout(new GridLayout(3, 2, 12, 12));
        
        customerView.add(new JLabel("Name: "));
        SLabel b = new SLabel();
        b.setSelector("name");
        customerView.add(b);

        customerView.add(new JLabel("Address: "));
        b = new SLabel();
        b.setSelector("address");
        customerView.add(b);

        customerView.add(new JLabel("Age: "));
        b = new SLabel();
        b.setSelector("age");
        customerView.add(b);

        JSplitPane s = new JSplitPane();
        s.setLeftComponent(left);
        s.setRightComponent(customerView);
        add(s);
    }
    
    ...

    public void refreshCustomerView() {
        customerView.refresh();
    }

The SList is bound to its model using three selectors:

  • setSelector specifies the property that will be used to provide data for the list: in this case a list of customers in the model
  • setTextSelector specifies the property of each model in the list that will be drawn by the list renderer: in this case, the name of each customer
  • setSelectionSelector specifies the property that will be bound to the list's current selection: in this case the "selection" property.

Note that the right-side panel "customerView" is bound to the same "selection" property that the SList's selection is bound to: the customer view shows properties of the currently selected customer.
