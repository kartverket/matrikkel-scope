An example using active models (BasicModels) that includes submodels.

The ActivesubmodelModel

Based on samples.swing.activemodel.ActivemodelModel, this BasicModel includes a PersonModel property that is itself a BasicModel. Similarly, PersonModel includes a org.scopemvc.model.collection.ListModel that is also a BasicModel. In order for ModelChangeEvent propagation to take place, model developers must ensure that submodels are listened to using: 

    listenNewSubmodel(PERSON);
after unlistening to old submodels with 
    unlistenOldSubmodel(PERSON);

For example: 

    public void setPet(PetModel inPet) throws ModelException {
    	unlistenOldSubmodel(PET);
        pet = inPet;
        listenNewSubmodel(PET);
        fireModelChange(VALUE_CHANGED, PET);
    }

Note that the implementation of ListModel and ArrayModel handles listening and unlistening to their elements as they are added, removed and changed.
